# УХИЛЯНТ v16 — INK CITY / TELEGRAM MINI APP

> Полный проект для GitHub + Render. Эта сборка обновляет v15, не удаляет Supabase, не сбрасывает аккаунты и не требует SQL-миграций.

## Что нового в v16

- Художественно расширены 36 SVG-локаций: вывески, автомобили, дворы, NPC, детали интерьеров, текстуры, тени, разные дневные и ночные сцены.
- Анимации CSS: дым от сигареты, качание деревьев, приближение/раскачивание бусика, мигалки, патруль, окоп и условный эффект стрельбы. Персонаж остаётся редактируемым и отдельным от фона.
- **Вулиця** в нижнем меню: новый серверный выход на улицу раз в 45 секунд. Риск задержания 14% днём или 7% в комендантский час (до бонусов жилья и прокачки). Результат формируется сервером.
- Игровой комендантский час с 00:00 до 05:00 по фиксированному игровому времени UTC+2. Ночью риск задержания ниже; если задержан — отправляется на позиции в рамках **вымышленного игрового сценария**. Длительность сцены 85 секунд; за завершение — игровые награды. Днём задержание запускает 60-секундную сцену ТЦК и полиции.
- Три виртуальные валюты: ₴, **scrap**, **crowns**. Scrap и crowns добываются в уличных событиях. Внутриигровые улучшения: «Тіньовий маршрут», «Фартовий жетон», «Пачка цигарок», «VIP перепустка».
- Действующие механики Telegram Stars остаются в разделе жилья и требуют отдельно настроенного безопасного приёма платежей. Stars **не включены автоматически** и не начисляются за нажатие.
- Меню приведено к 5 крупным разделам внизу с группировкой остальных в «Меню». Карточки и кнопки стали компактнее; добавлены разные сетки для телефона, горизонтального телефона и ПК.
- При запуске Mini App запрашивается `expand()` и, если поддерживается, `requestFullscreen()`. В портретной ориентации показывается компактная подсказка повернуть телефон. Телеграм может отказать в fullscreen на старых версиях — принудительный разворот без разрешения ОС невозможен.
- Добавлен рейтинг уличной активности по количеству выходов, без возможности накручивать его произвольными запросами.

## Установка поверх v15

1. Сделайте резервные копии репозитория GitHub и таблицы Supabase `players`. Это обязательно перед обновлением игровой экономики.
2. Распакуйте этот ZIP. Замените в GitHub файлы `server.js`, `uhylyant.html`, `uhylyant-ui.js`, `uhylyant-account.js` и остальные файлы из архива; папку `assets` копируйте полностью, сохраняя структуру.
3. В Render: **Build Command** `npm install --omit=dev && npm run check && npm run verify`; **Start Command** `npm start`.
4. В Render Environment должны быть `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN` (свежий, не опубликованный) и `PUBLIC_URL` с HTTPS-адресом Render. Токены в GitHub не загружайте.
5. Запустите Deploy, откройте Mini App через @Uhilyant_UAbot, перезапустите Telegram Mini App. При старом кэше обновите страницу и проверьте загрузку новых SVG.
6. Проверьте вход в старый аккаунт, редактор, 5 кнопок навигации, вкладку «Вулиця», смену локаций, здоровье и работу; проверьте рейтинг улицы.

## Что протестировано

- Синтаксис всех JS и встроенного игрового JS, XML 36 SVG; локальный запуск сервера и наличие статических ассетов.
- 30 проверок API в **локальном режиме с временной базой**, включая защиту от повторных уличных действий, безопасное отклонение чужого оборудования, недоступных товаров и ставок.
- Запуск с настоящим Render/Supabase/ботом Telegram, реальная оплата Stars и достоверный визуальный прогон в Chrome на устройствах **не подтверждены**. Локальная браузерная среда блокировала доступ к тестовому адресу, поэтому скриншоты игры после установки проверить дополнительно.

## Ограничения

Графика — оригинальная комиксная SVG-стилизация и CSS-анимации, **не** точная копия «Тюряги» и не полноформатная покадровая анимация. В игре используются только виртуальные игровые операции. На ПК управление доступно без поворота экрана; на телефоне предпочтительна альбомная ориентация, но портретная не блокируется.

# Ухилянт v15 — COMIC MOTION · Telegram Mini App

Это полный обновлённый проект (не патч), совместимый с существующими файлами v14 и сохранениями Supabase. Вариант для пустого GitHub тоже работает: распакуй весь ZIP. Если v14 уже работает, удалять старую базу или репозиторий не нужно; сначала сделай резервную копию.

## Обновление поверх работающей v14

1. Сделай резервную копию GitHub и Supabase `public.players`.
2. Замени `server.js`, `uhylyant.html`, `uhylyant-ui.js`, `uhylyant-account.js` файлами из ZIP и добавь все новые изображения в `assets/`.
3. Сохрани `uhylyant-social.js`, `package.json`, `render.yaml`, `scripts/`, `tests/`, `sql/` из архива. Не удаляй лишние старые файлы до успешной проверки.
4. Сохрани существующие секреты Render и таблицу Supabase. Пересоздавать аккаунты не нужно.
5. Deploy на Render, затем перезапусти Telegram Mini App.

## Шаг 1. GitHub — полный проект

1. Открой **свой GitHub-репозиторий** в GitHub. Выбери `Add file` → `Upload files`.
2. Распакуй ZIP **на компьютере** и загрузи **содержимое** распакованного архива, а не сам ZIP.
3. Сохрани иерархию папок. В корне должны лежать `package.json`, `server.js`, `uhylyant.html`, `uhylyant-ui.js`, `uhylyant-account.js`, `uhylyant-social.js`, `render.yaml`, `README_START_HERE_RU.md`. Папка `assets/` содержит **47 графических файлов**. Не пропускай новые `comic-tcc*`, `comic-work*`, `comic-hospital*`, `comic-casino*`, `comic-boss*` и `comic-transit*`.
4. Проверь на GitHub, что файлы действительно видны — архив ZIP как один файл Render не запустит.
5. Если GitHub через браузер не сохраняет папки корректно, используй GitHub Desktop и **Commit → Push**.

## Шаг 2. Supabase — НЕ УДАЛЯЙ ДАННЫЕ

- Удаление файлов GitHub **не удаляет** существующие аккаунты в Supabase. База хранится отдельно.
- Убедись, что Supabase проект активен и таблица `public.players` содержит старые записи (`id`, `data`).
- **Сначала экспортируй резервную копию** `players`.
- Если таблица УЖЕ есть, **НЕ запускай SQL из этого архива**. Он нужен только при абсолютно новой пустой базе (`sql/ONLY_IF_MISSING_players_table.sql`).
- В Render используй серверный секретный Supabase-ключ с разрешением читать/записывать `public.players`, не анонимный браузерный ключ. НИКОГДА не вставляй его в HTML/GitHub.

## Шаг 3. Render — запуск без старых файлов

Если твой прежний Render Web Service существует, оставь его. Укажи:
- **Root Directory:** пусто (корень репозитория)
- **Runtime:** Node
- **Build Command:** `npm install --omit=dev`
- **Start Command:** `npm start`
- **Health Check Path:** `/healthz`

Можно также создать новый сервис из `render.yaml`, но сначала проверь, не получится ли два одновременно работающих сервера с одной базой. **Не запускай две активные копии игры одновременно**, иначе перезапись игровых данных возможна.

**Render → Environment:**

| Имя | Значение |
|---|---|
| `SUPABASE_URL` | URL именно твоего существующего Supabase проекта |
| `SUPABASE_KEY` | серверный секретный ключ из этого же Supabase проекта |
| `TELEGRAM_BOT_TOKEN` | новый токен `@Uhilyant_UAbot`, полученный ПОСЛЕ отзыва старого |
| `PUBLIC_URL` | `https://ИМЯ-ТВОЕГО-СЕРВИСА.onrender.com` (точный адрес!) |
| `STARS_ENABLED` | `0` до отдельной настройки платежей |

Render автоматически выдаёт переменную `PORT` — руками её менять не нужно.

**ЗАЩИТА ОТ ПОТЕРИ ПРОГРЕССА:** если переменные Supabase не настроены, сервер теперь не запускает «временную» игру в оперативной памяти. Render Logs прямо сообщат, что именно отсутствует. Также сервер не стартует, если Supabase не загружает игроков.

## Шаг 4. Telegram Mini App — вход без формы

1. В `@BotFather` отзови СТАРЫЙ токен, ранее опубликованный в чате. НОВЫЙ токен храни только в Render Environment.
2. В настройках бота `@Uhilyant_UAbot` установи для **Main Mini App / Menu Button** URL `PUBLIC_URL`, где уже работает игра.
3. Открывай игру именно кнопкой Mini App Telegram, а не обычной ссылкой на веб-сайт.
4. Mini App передаёт подписанные `initData`. Сервер проверяет подпись новым токеном и связывает игрока с его Telegram аккаунтом.
5. При первом входе автоматически создаётся игрок; при последующих открывается тот же профиль. Старые аккаунты с логином/паролем можно отдельно привязать в разделе «Акаунт».
6. Если Telegram не передаёт `initData` или токен неверен, вместо формы логина появится ошибка. На обычном сайте вне Telegram вход по логину сохранён.

## Шаг 5. Проверка после деплоя

1. `https://YOUR-SERVICE.onrender.com/healthz` → **ok**.
2. `https://YOUR-SERVICE.onrender.com/api/ping` → `{ "ok": 1 }`.
3. Открой игру через бота, убедись, что окно пароля не появилось.
4. Настрой персонажа, смени локацию и перезапусти Mini App: настройки/прогресс должны сохраниться согласно правилам сохранения.
5. Проверь здоровье/голод, работу, квартиру, друзей, рейтинг, казино, группового босса.
6. Убедись, что аккаунт сохраняется в **той же** таблице Supabase и после перезапуска сервера остаётся на месте.

## Состав и особенности

- Главная игра: `uhylyant.html`
- Сервер и игровая логика: `server.js`
- Карьера, казино, город, здоровье, жильё: `uhylyant-ui.js`
- Telegram-вход / аккаунты: `uhylyant-account.js`
- Игроки, профили и подарки: `uhylyant-social.js`
- Все изображения/иллюстрированные локации: `assets/`
- Дополнительно: `scripts/setup-telegram-webhook.js` для добровольной интеграции платежей через Stars (НЕ нужен для обычной авторизации).

В v15 фон меняется по контексту: при задержании и перевозке ТЦК, на позициях, во время активной работы, а также в казино, больнице, карьере, недвижимости, рейтинге и арене босса. В дополнительных вкладках есть мини-сцена с тем же персонажем; главная сцена остаётся видимой после закрытия вкладки. Персонаж рисуется отдельно от фона и поддерживает редактирование кожи, волос и экипировки. На работе временно надевается форма без потери купленного снаряжения. Мобильный HUD: четыре быстрые кнопки сверху и пять пунктов снизу (прочее — в Меню). Анимация фона и персонажа учитывает `prefers-reduced-motion`.

**Смена v15:** действие «Розпочати зміну» запускает на сервере таймер 60–135 секунд (зависит от должности); по завершении игрок нажимает «Забрати зарплату». Раньше выплаты происходили мгновенно. Активная смена сохраняется в `world.workShift` в Supabase, в Telegram/браузере после перезахода её можно продолжить. Начать вторую или получить зарплату заранее нельзя, после выплаты действует пауза.

В игре всё ещё **два игровых кошелька** (`uah` главной игры и `world.cash` городских действий). Это особенность исходной архитектуры, не реальные деньги. Локация хранится локально на устройстве; основные характеристики — через сервер и Supabase.

**Не включай Telegram Stars, пока отдельно не проверишь защищённый webhook, политику возмещения и фактический приём платежей.** Для обычной игры и входа в бота webhook не требуется.

## Если что-то не запускается

- Render `Cannot find module @supabase/supabase-js` → проверь Build Command и наличие `package.json`.
- Render `FATAL: configure SUPABASE_URL and SUPABASE_KEY` → добавить два секрета.
- Render `FATAL: cannot load Supabase players` → проверить таблицу, права и подключение Supabase.
- Telegram «не передав дані входу» → открыть через правильно настроенный Mini App.
- Telegram «недійсні дані» → проверить, что токен ТОГО ЖЕ бота и старый токен отозван.
- Если раньше аккаунт был только на сайте, не регистрируй новую учётку вместо восстановления; привяжи его через «Акаунт».

## Предупреждения

Это полный **исходный код** и готовая структура репозитория, но установка не может быть завершена без твоих приватных переменных Render и существующей базы Supabase. Реальное развёртывание, работа Telegram и внешней Supabase требуют проверки на твоей стороне. Тестировать секреты в чате не нужно.

## Технические проверки проекта

- `npm run check` — проверка синтаксиса серверных JS.
- `npm run verify` — проверка всех важных файлов, SVG-локаций и синтаксиса встроенного JS.
- В папке `tests/` есть тесты API и 5 сценариев Telegram-входа (для разработчика, требуют тестовой среды; **не запускайте на боевой базе**).


## Проверено для v15

- `npm run check` и `npm run verify` — пройдены.
- `NODE_PATH=... node tests/test_v15_shift.js` — локальный тест API смены: старт, досрочная выплата, защита от повторной выплаты, кулдаун и увольнение. Для такого теста нужен отдельный тестовый Supabase-заглушка и флаг `ALLOW_EPHEMERAL_DB=1`; не использовать его на Render.
- Chromium в изолированной тестовой странице: экраны 360px, 390px и 1280px, редактор персонажа и пять частей снаряжения, открытие здоровья/работы/рейтинга, отсчёт смены и меню; без ошибок JavaScript. Прямые HTTP-адреса Chromium здесь блокируются, поэтому тест использовал HTML-фикстуру с имитацией API — это НЕ тест реального продакшн-аккаунта.
- Запуск локального сервера и выдача новых SVG — HTTP 200.

**Ограничения:** полноценное развёртывание в Render, работа с реальной Supabase, авторизация в живом Telegram и тест на реальных смартфонах выполняются после обновления на вашей стороне. Изображения — авторские стилизованные SVG в цветах и контурах логотипа, но это не профессионально анимированные рисованные ролики.
