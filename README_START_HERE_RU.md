# УХИЛЯНТ v23 — CLAUDE STYLE, PERSONAL HOUSE

Версия собрана **из последних загруженных пользователем файлов**:
`uhylyant(2).html`, `server(5).js`, `uhylyant-ui(2).js`, `package.json`.
Совместимый `uhylyant-account.js` взят из предыдущей рабочей сборки.

## Что сделано

- Основа — аккуратная 2D-комиксная графика Claude из ваших файлов. **Игровые правила, ставки, сохранения, авторизация и экономика не переписаны.**
- На экране «Дім» **каждый игрок автоматически видит свою хату**, а не общий двор.
- Начальная хата = `shack`. После входа купленная и выбранная недвижимость загружается через `/api/world` из `world.housing.current` данного игрока.
- Значение `uhy_house` в общих настройках браузера больше не используется, чтобы игроки одного браузера не наследовали чужой фон.
- Пять квартир получили индивидуальные превью из родного графического движка `UHART.paint`.
- Шесть существующих основных боссов имеют карточки с портретами из `UHART.svg`, прогрессом и статусом. Удары, награды и HP работают по прежним правилам.
- Убрана повторная выдача раздела «Хати» внутри «Вулиця». Жильё управляется через отдельный раздел.
- Для дополнительных разделов добавлены маленькие анимированные сцены с тем же персонажем и постоянные кнопки «Хата», «Вулиця», «Казино», «Робота», «Боси», «Вийти».
- На ПК: большая сцена слева, компактные блоки справа. На телефоне в портрете: вертикально. В альбомном режиме: сцена слева, карточки справа.
- Исправлено дублирование панели навигации между основной игрой и модулем аккаунтов: когда модуль создаёт общий dock, исходные кнопки остаются как скрытые action-targets, а на экране одна панель.

## Установка в GitHub и Render

1. Сохраните резервные копии GitHub и таблицы `players` в Supabase.
2. Распакуйте ZIP. Загрузите **содержимое папки** в корень репозитория, включая `uhy-polish.css`, `uhy-polish.js` и `assets`.
3. Оставьте существующие значения `SUPABASE_URL`, `SUPABASE_KEY` и другие секреты в Render. **Не публикуйте секреты в GitHub**.
4. Build command: `npm install --omit=dev`.
5. Start command: `npm start`.
6. Деплой в Render. В Telegram Mini App перезапустите игру; затем проверьте вход, сохранения, дом и переходы.

При открытии **локального** `uhylyant.html` рядом должны лежать `uhy-polish.css` и `uhy-polish.js`. Без сервера доступны только части клиентского интерфейса; аккаунты, Supabase и дополнительные серверные экраны требуют Render.

## Проверки

- `node --check` — все JS-файлы и оба встроенных скрипта HTML.
- Smoke test HTTP без реальной Supabase: `/healthz`, `/`, `/uhy-polish.css`, `/uhy-polish.js`, `/api/register`, `/api/world`, `/api/world houseEquip`.
- Playwright Chromium (автономное отображение без внешних запросов): 1280×800, 390×844, 844×390, разделы «Дім» и «Бої» — нет JS ошибок или горизонтального выхода за границы. Шесть портретов боссов отрисовываются.
- Проверка интерфейса с подключённым старым account-navigation: **одна**, а не две навигационные панели.
- Иллюстрированная сцена для вложенных вкладок проверена в изолированной DOM-модели; настоящий Telegram и живые аккаунты Supabase отсюда не проверялись.

## Важное ограничение

Эта версия намеренно **не добавляет серверные механики, отсутствующие в загруженном пользователем исходнике**. Ранее обсуждавшиеся отдельные ключи боссов, Stars-оплата, здоровье и автоматический вход Telegram не восстанавливаются из памяти о старых версиях: для них требуется их актуальный исходный серверный код. Здесь сохранены механики последней загруженной основы.

Временные test-аккаунты, созданные при локальном smoke test без Supabase, НЕ являются пользовательскими аккаунтами.
