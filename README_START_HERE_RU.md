# Ухилянт v24 — Living City / этап 1: живые новости и профили

Это полный проект на основе твоей последней работающей **v23.3 с восстановленным Telegram-входом**. Оригинальное оформление Claude-style и механики v23.3 сохранены. Переписывать базу или удалять старые аккаунты НЕ требуется.

## Что добавлено

- **Новости города**: серверная лента реальных игровых действий с именем, временем и типом события. Новые события доставляются через Server-Sent Events (SSE) и дополнительно проверяются раз в 3,5 секунды, если соединение прервано.
- Действия: появление нового игрока, работа/смены, ежедневный бонус, казино/джекпоты, покупка/смена хаты, изменение одежды, ТЦК/побеги, бои/удары, победы бригад, друзья, больница, повышение уровня и начало/окончание учебки.
- **Просмотр игроков**: клик по имени в новостях, топе или друзьях, а также поиск по 8-символьному ID. Профиль показывает **тот же рисованный стиль героя** и интерьер выбранной хаты, одежду, работу, игровой HP, уровень, победы, лучший удар, смены, джекпоты, игровую бригаду и игровой статус.
- Из чужого профиля можно отправить запрос в друзья.
- **HP + больница** в разделе «Хати»: старт 100 HP, задержание ТЦК снижает HP, лечение +45 HP стоит 320 игровых ₴, раз в четыре часа. Существующие аккаунты без поля HP получают 100 HP по умолчанию.
- Безопасность: в публичном профиле **нет** почты, паролей, токенов, Telegram ID или секретных ключей. События генерируются сервером, после подтверждённого игрового действия.
- **Сохранение ленты**: используется одна зарезервированная метазапись `UHYNEWS1` внутри уже существующей таблицы Supabase `players`. Дополнительных таблиц или SQL-миграций нет. Прежние новости в полях `news` игроков подхватываются автоматически при первой загрузке.

## Обновление работающей v23.3 (рекомендуется)

1. Сохрани резервную копию GitHub и Supabase `players`.
2. Из **патча** v24 замени в корне репозитория **`server.js`** и **`uhylyant-ui.js`**.
3. Добавь новый файл **`uhy-live.css`** в корень репозитория рядом с `server.js`.
4. Остальные файлы (`uhylyant.html`, `uhylyant-account.js`, `uhy-polish.css`, `uhy-polish.js`, `assets`, `package.json`, `render.yaml`) **не удаляй**.
5. Нажми Commit & Push, проверь Render Deploys → Live. Не меняй переменные `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN` без необходимости.
6. Открой игру через Telegram Mini App, перейди в «Новини», сделай действие другим аккаунтом и проверь появление строки в ленте; кликни на имя для открытия профиля.
7. Убедись, что в Render Logs нет ошибок `Збереження новин`. Если есть — Supabase блокирует сохранение служебной записи, и надо проверить права серверного ключа / схему `players`.

**Важное предупреждение:** не публикуй токен Telegram и ключ Supabase в GitHub. Ранее опубликованный токен бота должен быть отозван в BotFather.

## Развёртывание с нуля

Распакуй **полный** архив в корень GitHub (не во вложенную папку). Render:
- Build Command: `npm install --omit=dev`
- Start Command: `npm start`
- Environment: `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`; `PUBLIC_URL` при необходимости для восстановления пароля/платежей.

## Что проверено

- 17 API-интеграционных сценариев: Telegram-игроки, профили, приватность, события, хата, бонусы, сохранение ленты и профилей после рестарта, раздача HTML/CSS.
- 13 регрессионных сценариев Telegram-входа и привязки старого аккаунта.
- SSE: сервер мгновенно доставляет действие игрока в подписанную ленту.
- Автономный Chromium-прогон разметки и кнопок новостей/профиля: 390×844, 844×390 и 1280×800 без горизонтального переполнения.
- Синтаксис JS (сервер, основной клиентский UI, встроенный скрипт социальных экранов).

**Ограничение проверки:** прямое открытие локального сайта в Chromium было заблокировано тестовой средой, поэтому автономные UI-тесты используют тестовые SVG-фигуры вместо реальных рисованных элементов. Функции рисования в самой игре вызывают исходный `UHART` и рисуют настоящие игровые аватары. Реальные Render/Supabase/Telegram после установки нужно проверить отдельно.
