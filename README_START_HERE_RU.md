# УХИЛЯНТ v16 · INK CITY

Полный проект браузерной игры и Telegram Mini App. Загружай **все файлы из папки** в корень GitHub-репозитория, сохраняя вложенные каталоги `assets/`, `scripts/`, `sql/`, `docs/` и `tests/`.

## Что нового

- Новые графические SVG-иллюстрации двора, улицы и 5 квартир (всего 14 перерисованных вариантов день/ночь). Сохранились остальные фоны (ТЦК, дорога, позиции, работа, казино, больница, арена и т. п.).
- Персонаж — редактируемая SVG-модель с дополнительными деталями, одеждой, татуировками и отрастающей бородой; это **не статичная картинка**.
- Анимированное окружение (дым сигареты, качающиеся деревья, бусик и патруль, визуальная вспышка у позиции, сцена окопа). Увертка нужна только для игровой атмосферы; не является инструкциями.
- Единая сцена на главной и во вспомогательных вкладках; при событиях ТЦК отображается патруль/бусик, при «нуле» — форма и стилизованный автомат.
- «Вулиця»: отдельное серверное событие, cooldown 45 секунд, дневной риск выше ночного. В **вымышленный игровой комендантский час 00:00–05:00 (фиксированное UTC+2)** шанс задержания ниже, но при задержании начинается 85-секундная игровая сцена на позициях; в дневное время задержание — 60-секундная проверка у бусика. Результаты рассчитывает сервер.
- Награды за выход: игровые ₴, XP, scrap и иногда crowns. За scrap/crowns можно купить усиления, которые проверяются на сервере. Прежняя покупка квартир за Telegram Stars оставлена опциональной и отключена по умолчанию.
- Дополнительные рейтинги по успешным вылазкам и редкой валюте. Остались дружба, совместные боссы, работа с таймером, жильё, казино, аккаунты и Telegram-автовход.
- Телефон: подсказка повернуть в альбомный режим, адаптивное меню (5 основных кнопок снизу, 4 быстрых сверху, остальные в «Меню»). Telegram WebApp пытается `expand()` и `requestFullscreen()` при наличии соответствующей функции SDK. Telegram/OS может отказать в полноэкранном режиме — принудительное управление системным UI невозможно.

## Установка на Render

1. **Сделай резервную копию базы Supabase и работавшей версии GitHub до деплоя.** Код не удаляет таблицу `players`.
2. Распакуй ZIP на компьютере. Загрузи **содержимое**, а не сам ZIP, в корень GitHub.
3. Render: **Build Command** — `npm install --omit=dev && npm run check && npm run verify`.
4. Render: **Start Command** — `npm start`.
5. Проверь существующие переменные: `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN` (новый секретный токен, никогда не в GitHub), `PUBLIC_URL` (точный HTTPS URL Render).
6. Старый токен Telegram, который публиковался в чате, должен быть отозван через @BotFather. В ZIP токенов нет.
7. Не задавай `ALLOW_EPHEMERAL_DB=1` на рабочем Render: он нужен только для локального теста без базы. Если Supabase не настроена, production-сервер прекращает запуск, а не теряет данные тихо.
8. Render → Deploy latest commit. Перезапусти Telegram Mini App через бот, при необходимости обнови кэш.

## Проверка после деплоя

- В Telegram новый игрок входит без пароля, а старый возвращается в свою учётную запись.
- Поворот телефона: текст подсказки исчезает в альбомном положении. Проверь, что нет горизонтальной прокрутки и кнопки кликабельны.
- «Вулиця»: выход, cooldown, получение награды, изменение фона при задержании; отрицательный исход случаен — специально гарантировать его не надо.
- «Робота»: форма, таймер, выплата только после окончания.
- «Хати»: переключение доступного жилья, сохранение после обновления страницы.
- «Казино», «Друзі», «Рейтинг»: проверка авторизации и сохранений.
- Render Logs: нет ошибок при старте и записи в Supabase.

## Что важно понимать

**Это значительное улучшение SVG/HTML/CSS, но не полная ручная иллюстрация уровня показанного референса**: для такого уровня потребуется нарисовать отдельные десятки кадров анимации и спрайт-листы под разные комплекты одежды. Анимации в сборке — CSS, не полноценное 3D/мультипликационное производство.

Автоматически пройдены 38 проверок структуры, синтаксиса, SVG, API и базовых ограничений экономики. Один успешный изолированный браузерный сценарий проверил ширину 360 px, открытие редактора, пяти кнопок меню, вкладку улицы и серверное действие. Полная реальная проверка работы Telegram, Supabase и Render **не выполнена**; браузерные тесты на всех разрешениях ограничены средой. Перед основным деплоем рекомендуется тестовый сервис Render.

## Валюты и донат

`₴` — виртуальная обычная валюта, `scrap` — лут за задания, `crowns` — редкая игровая валюта. Сам по себе появившийся `crowns` не эквивалентен Telegram Stars. Покупка квартиры за Stars включается только после настройки безопасного Telegram webhook; до этого `STARS_ENABLED=0`. Не включай платежи без тестирования webhook и защиты от повторного начисления.
