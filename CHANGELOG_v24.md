# Изменения v24 · Living City

- Реальные серверные события игровых действий; единая лента вместо копирования событий в каждого игрока.
- Сохранение ленты в Supabase `players` под зарезервированным ID `UHYNEWS1`.
- SSE `/api/news/stream` + опрос `/api/news?limit=80` для восстановления пропущенных событий.
- Авторизованный маршрут `/api/player/profile?id=...` с ограниченным безопасным набором полей.
- Новости, рейтинг, друзья → кликабельные имена игроков, карточка с тем же аватаром/домом (`UHART`).
- Серверный HP; больница в разделе «Хати»; логирование ТЦК/смен/одежды/боёв/приобретения жилья.
- Сохранены Telegram HMAC-авторизация и существующие игровые правила v23.3.
- Ошибки, найденные и устранённые тестами: первый запрос ленты ограничивался одним событием; профиль падал после рестарта при `brigade: null`; служебный ID ленты сделан 8-символьным алфавитно-цифровым.
