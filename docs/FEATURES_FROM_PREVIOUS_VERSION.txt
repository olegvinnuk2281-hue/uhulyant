УХИЛЯНТ v13.1 — ОДНО НАЖАТИЕ В TELEGRAM (БЕЗ ФОРМЫ ЛОГИНА)

ЧТО ИЗМЕНЕНО
- В Telegram Mini App игрок сразу проходит подписанную авторизацию.
- Новый игрок получает отдельную учетную запись и персонажа автоматически.
- При повторном запуске используется существующая запись Telegram.
- Успешный вход не показывает окно с паролем или регистрацией.
- Если Telegram не передал initData или Render не настроен, показывается
  понятная ошибка с кнопкой «Повторить»/«Открыть в боте», но НИКОГДА
  не создается аккаунт по неподтвержденному ID.
- Прямая версия сайта вне Telegram сохраняет обычную регистрацию и вход.
- Старые сайт-аккаунты не удаляются; привязка в разделе «Акаунт».

ОБЯЗАТЕЛЬНЫЕ НАСТРОЙКИ (БЕЗ НИХ АВТОВХОД НЕ РАБОТАЕТ)
1. @BotFather → /mybots → @Uhilyant_UAbot → Bot Settings → Configure Mini App
   (или Menu Button) → HTTPS-адрес игры на Render.
   Запускать именно кнопку «Open App», а НЕ просто отправленную ссылку на сайт.
2. @BotFather → API Token → Revoke старый токен, который был отправлен в чат.
   Получить новый токен и добавить в Render → Environment → TELEGRAM_BOT_TOKEN.
   НИКОГДА не добавлять токен в GitHub, ZIP, код браузера или чат.
3. Сохранить существующие SUPABASE_URL/SUPABASE_KEY, PUBLIC_URL.
   В Render сделать Deploy latest commit.
4. Проверять через кнопку бота / ссылку https://t.me/Uhilyant_UAbot?startapp
   (основное Mini App должно быть настроено через BotFather).

УСТАНОВКА
- Сделать бэкап GitHub и Supabase public.players.
- Заменить uhylyant-account.js из этого архива. Остальные файлы соответствуют v13.
- НЕ удалять старые аккаунты/таблицу Supabase и переменные Render.
- Жестко обновить Mini App, закрыв и заново открыв его в Telegram.

ДИАГНОСТИКА
- Появляется «Telegram не передав дані входу»: игра открыта простым URL,
  не настроено настоящее Mini App или Telegram WebApp SDK не предоставил initData.
- «Telegram не налаштований на сервері»: отсутствует TELEGRAM_BOT_TOKEN в Render.
- «Недійсні або застарілі дані Telegram»: токен не от того бота, дата устарела
  или initData изменены; проверь @BotFather и Render, открой Mini App заново.
- В обычном Chrome логин остается специально — без Telegram нет подписанной личности.

ПРОВЕРКА: JS синтаксис + тесты логики входа. Реальный Telegram и ваши Render/Supabase
здесь не подключены, поэтому финальный тест выполняется в вашем Mini App.

-------------------- ОСТАЛЬНАЯ ИНСТРУКЦИЯ V13 --------------------

УХИЛЯНТ — COMPETITIVE COMIC v13 (Render, Supabase, Telegram Mini App)
===================================================================

ЭТО ОБНОВЛЕНИЕ, НЕ ПЕРЕУСТАНОВКА БАЗЫ ДАННЫХ.

СОДЕРЖАНИЕ
- server.js — игровой сервер и проверка действий, Telegram авторизация, опциональные Stars
- uhylyant.html — игра, визуальные сцены и редактор персонажа
- uhylyant-ui.js — казино, карьера, жильё, здоровье, работа, бригады
- uhylyant-account.js — вход и Telegram Mini App
- uhylyant-social.js — публичные профили, переводы и подарки
- assets/ — рисунки двора, улицы, крыши, леса и 5 типов квартир день/ночь
- scripts/setup-telegram-webhook.js — однократная конфигурация webhook (не обязательна для входа)

ЧТО РАБОТАЕТ В КОДЕ
1. Собираемый персонаж: внешность и экипировка из принадлежащего инвентаря;
   смена локаций без фоновой фотографии персонажа.
2. Борода: сервер добавляет 1 мм каждые 5 реальных минут, и офлайн тоже;
   максимум 35 мм. Кнопка бритья обнуляет длину.
3. Голод и здоровье зависят от серверного времени; меню еды, отдых, больница.
   Лечение и пища оплачиваются виртуальными деньгами. Работа требует здоровья/сытости.
4. 5 ступеней жилья: стартовая халупа (0), комната (4500), квартира (17000),
   лофт (47000), пентхаус (100000) — цены во ВНУТРИИГРОВЫХ гривнах.
   Есть ветка получения за достижения: 5, 20, 40, 60 разных рабочих дней;
   для дорогих квартир также уровень и боссы. Покупка за виртуальную валюту доступна
   без условия рабочих дней. День/ночь и интерьеры жилья автоматически переключаются.
5. Казино: маленькие ставки чаще выигрывают маленькие суммы, джекпоты редкие;
   сервер считает результат. Виртуальные ставки, никаких ставок на реальные деньги.
6. Профили и топ-100 по нескольким показателям. Просмотр развития соперника.
7. Добавление/удаление друзей по ID, защищённые переводы виртуальных денег
   ТОЛЬКО взаимным друзьям (лимит 5000/сутки) и подарки еды.
8. Бригады: создать, пригласить по коду, покинуть; выбранный групповой босс,
   30 секунд между ударами, награда членам отряда.
9. Карьера и учебка: вакансии за навыки/дни, учебка только после задержания,
   анимации, работа за виртуальную валюту.
10. Telegram Mini App авторизация с HMAC-проверкой initData на сервере.
    При первом входе из Telegram создаётся новая учётная запись и персонаж;
    существующий аккаунт с сайта можно ПРИВЯЗАТЬ через «Акаунт» — старый логин и пароль.
    Никаких поддельных Telegram ID с клиента не принимается.
11. Необязательная покупка комнат/квартир за Telegram Stars с проверкой webhook,
    pre_checkout_query, суммы, валюты XTR, Telegram User ID и idempotency charge ID.
    НЕЛЬЗЯ выдавать квартиру только по нажатию кнопки клиента.

БЕЗОПАСНАЯ УСТАНОВКА
1. Сохранить копию GitHub и СНАЧАЛА экспортировать Supabase public.players.
2. Загрузить все файлы из ZIP, включая НОВЫЙ uhylyant-social.js, package.json,
   папку assets и server.js; ненужные старые файлы пока можно не удалять.
3. Render Environment: оставить свои SUPABASE_URL и SUPABASE_KEY (не публиковать).
   Добавить TELEGRAM_BOT_TOKEN — НОВЫЙ токен после отзыва прежнего в BotFather.
   Добавить PUBLIC_URL=https://ВАШ-АДРЕС-ИГРЫ (без слеша в конце).
4. В Render: Build command «npm install», Start command «npm start»;
   Render назначает переменную PORT сам. Проверить /healthz и /api/ping.
5. В BotFather установить HTTPS-URL Mini App и убедиться, что он открывает
   вашу новую версию. Если открывается прежняя версия — перезапустить Mini App.
6. Проверить вход в старый сайт-аккаунт, привязку в Telegram (не перезаписывать старую базу!),
   сохранение персонажа, покупку и выбор жилья, еду, больницу, казино, друзей,
   группового босса и рейтинг.

ТОКЕН БОТА
Ранее токен Telegram был опубликован в переписке — СРОЧНО отзовите его в @BotFather,
сгенерируйте НОВЫЙ токен и вводите его ТОЛЬКО в секретной среде Render.
Не присылайте токен никому и не добавляйте в файлы GitHub.

КАК ВКЛЮЧИТЬ STARS (НЕОБЯЗАТЕЛЬНО)
1. В Render добавить STARS_ENABLED=1.
2. Создать TELEGRAM_WEBHOOK_SECRET — случайная строка 32–64 символа из A-Za-z0-9_-.
3. Оставить TELEGRAM_BOT_TOKEN и PUBLIC_URL из шага выше.
4. Однократно выполнить в окружении с ЭТИМИ же переменными:
   node scripts/setup-telegram-webhook.js
   Это установит webhook по адресу PUBLIC_URL/api/telegram/webhook.
5. ВАЖНО: setWebhook заменяет текущий webhook бота. Если у вас уже есть
   другой Telegram-бот-сервер/обработчик, объедините обработчики ДО включения.
6. Убедиться, что HTTPS доступен из интернета, pre_checkout_query вовремя
   обрабатывается сервером, а успешные платежи отражаются в Supabase.
7. Цены в Stars заданы для игры: комната 49 XTR, квартира 149 XTR,
   лофт 349 XTR, пентхаус 699 XTR. Пересмотрите цены до включения продаж.
Без STARS_ENABLED=1 игра работает, квартиры покупаются за игровую валюту.

ПОЖАЛУЙСТА, ПРОВЕРЬТЕ НА ТЕСТОВОЙ КОПИИ
Автоматически проверено: синтаксис JS, XML-фоны, API, защищённый вход,
игровая экономика, друзья/подарки/переводы, бригады, Stars webhook на заглушке Telegram.
Не проверено на вашей реальной Supabase, Render или Telegram; автоматический
браузерный движок в среде проверки блокирует localhost. Нет гарантии отсутствия
всех игровых/визуальных ошибок. Старые игроки/балансы не обнуляются намеренно.

ВАЖНО О СОХРАНЕНИЯХ
- Основные старые данные сохраняются в Supabase public.players (id,data JSON).
- Новые world.vitals, world.groom, world.housing, social/brigade и payment поля
  хранятся внутри data, отдельные таблицы не требуются.
- Некоторые настройки локаций хранятся в локальном браузере; выбор купленного
  жилья и серверная длина бороды доступны на других устройствах.
- В игре до сих пор два разных виртуальных кошелька: основной S.uah
  и городской world.cash (работа, казино, жильё, переводы). Это ограничение
  существующей архитектуры, их нельзя путать с реальной валютой.
