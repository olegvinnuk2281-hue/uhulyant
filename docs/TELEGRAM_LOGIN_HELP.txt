УХИЛЯНТ v13.1 — АВТОВХОД ЧЕРЕЗ TELEGRAM

БЫСТРОЕ ОБНОВЛЕНИЕ существующей v13:
1. Сделайте бэкап GitHub и Supabase.
2. Замените ТОЛЬКО uhylyant-account.js из папки этого обновления.
3. Deploy на Render и заново откройте Mini App через кнопку бота.
4. В Render обязательно есть TELEGRAM_BOT_TOKEN с НОВЫМ токеном от @Uhilyant_UAbot.
5. BotFather: настроить Main Mini App / Menu Button, HTTPS URL игры.

Если пользователи открывают обычную ссылку на сайт, Telegram не передает
подписанные initData: автоматически входить за них безопасно невозможно.
Открывайте через: https://t.me/Uhilyant_UAbot?startapp

Если на Render НЕ задан новый токен — вместо окна логина увидите сообщение об ошибке.
В браузере вне Telegram логин сохранен для прежних игроков.

Проверено: node --check, пять UI-сценариев Chromium. Не проверено: живой бот, Render,
Supabase; для этой проверки нужны настроенные секреты и реальный запуск Telegram.
