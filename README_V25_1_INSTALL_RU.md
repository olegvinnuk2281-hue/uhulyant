# Ухилянт v25.1 — серверное колесо, казино и таймеры

## Что включено

- Ежедневное колесо (раз в 24 часа). Результат выбирает сервер, сохраняет до начала анимации. Шансы: 32%, 28%, 18%, 10%, 6%, 3.5%, 1.8%, 0.6%, 0.1%.
- Последний приз, cooldown и время следующего вращения сохраняются при выходе из Telegram и после перезапуска сервера.
- Исправлено: старый бонус на главной странице теперь не начисляет виртуальные деньги локально и ведёт к одному серверному колесу.
- Исправлено: после выигрыша локальные гривны, инвентарь и время бонуса синхронизируются с уже сохранённым на сервере результатом.
- Работа: серверная смена 60–135 секунд, зарплата только по завершении, однократное получение, откат не перезапускается при закрытии Telegram.
- Исправлен обратный отсчёт смены: время течёт по серверной отметке, но отображается с непрерывным счётчиком.
- Казино: единый набор из шести нарисованных SVG-символов вместо эмодзи; тройные комбинации и таблица выплат отображают один и тот же набор.
- Сохранена лента новостей и профили из v24, жильё, боссы/ключи из доступной исходной сборки, Telegram-авторизация.
- Музыка и звуки: оригинальная синтезированная мелодия и эффекты кнопок. Включаются вручную через настройки, по умолчанию выключены.

## Установка

1. Сохрани резервную копию текущей рабочей версии GitHub и данных Supabase.
2. Если установлен v24/v25: распакуй PATCH и замени одноимённые файлы в корне репозитория, добавь шесть файлов assets/casino-*.svg.
3. Если хочешь полностью заменить игровые файлы: распакуй FULL и загрузи *содержимое архива* в корень репозитория (server.js и package.json должны лежать в корне). Не нужно удалять Supabase или Render-переменные.
4. Render: Build `npm install --omit=dev`, Start `npm start`. Проверь `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`, `PUBLIC_URL` (токены и ключи не публикуй).
5. Проверка после Live: вход Telegram без пароля, сохранение старого профиля, кнопка бонуса на главной, колёсное вращение ровно один раз, смена без сброса при повторном открытии, казино на телефоне, новости и профили.

## Важные ограничения

- Автотесты выполнялись на локальной тестовой базе, не на настоящих Render и Supabase.
- Серверное блокирование повторного вращения рассчитано на один активный Node.js-инстанс. Для горизонтального масштабирования потребуется атомарная блокировка через БД.
- Серверные таймеры введены для ежедневного бонуса и дополнительной рабочей смены. Для прочих механик действуют правила их оригинальных систем; **не все** таймеры заменены на единую серверную архитектуру.
- Графика и анимация старых локаций сохранены; эта сборка не заменяет полностью арт всех экранов.
