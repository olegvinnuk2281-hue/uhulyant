УХИЛЯНТ — COMIC GAME UI v5

ЭТО РЕАЛЬНЫЙ ПАКЕТ ДЛЯ САЙТА, НЕ МАКЕТ-КАРТИНКА.
Пакет внедряет рисованный фон в живую страницу игры, стилизует все окна и вкладки,
добавляет автоматическое дневное/ночное изображение по UTC+2 и анимированные
элементы окружения (параллакс, дымка, мигающий огонь, интерактивный кот).
Старая игровая логика, аккаунты, Supabase и сохранения остаются в прежних файлах.

УСТАНОВКА
1. Сделайте бэкап Supabase public.players и текущих файлов.
2. Скопируйте в папку сервера ВСЕ файлы из ZIP, сохранив папку assets.
3. Ваш старый uhylyant.html (или uhylyant (1).html) оставьте в этой папке.
4. Запустите сервер и очистите кеш страницы (Ctrl+Shift+R).
5. Убедитесь, что доступны /assets/noir-courtyard-day.webp и
   /assets/noir-courtyard-night.webp.

ИЗМЕНЕНИЯ
- В игре показывается комикс-сцена с персонажами и городом, а не
  сгенерированный скриншот интерфейса.
- Каждая серверная вкладка получила единые цвета, панели, типографику,
  фактурные рамки, кнопки и hover/active анимации.
- Одна нижняя навигация, предусмотренная предыдущей версией.
- День 06:00–19:59, ночь 20:00–05:59 по фиксированному UTC+2.
- Анимированный городской фон и интерактивный кот.
- «Продовжити гру» НЕ добавлялась.
- Никаких изменений SQL и сброса аккаунтов.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
- Это значительное обновление интерфейса, но не полный перерисованный
  художественный ассет для КАЖДОЙ сцены; у некоторых старых экранов
  сохраняется исходная композиция.
- Изображение — фон сцены, а не отдельные анимированные спрайты людей.
- Реальная проверка на вашем Supabase и в мобильных браузерах не проведена.
- Для production требуется ручной регрессионный тест (регистрация,
  вход, сохранения, навигация, казино, работы, бригады).
