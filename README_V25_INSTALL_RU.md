# УХИЛЯНТ v25 — установка

## Если у тебя уже установлена v24 Living City

Распакуй `Uhilyant_v25_CASINO_WHEEL_PATCH.zip` и загрузи в **корень** GitHub с заменой:

- `server.js`
- `uhylyant.html`
- `uhylyant-ui.js`
- `uhy-polish.css`
- `uhy-polish.js`
- `assets/casino-cherry.svg`
- `assets/casino-lemon.svg`
- `assets/casino-star.svg`
- `assets/casino-medal.svg`
- `assets/casino-diamond.svg`
- `assets/casino-seven.svg`

Ничего не удаляй из Supabase. Не удаляй `.env` и переменные Render. Сохраняй текущую конфигурацию бота.

## Если работает v23.3, а v24 нет

Используй полный архив `Uhilyant_v25_FULL.zip` (в нём также находятся все файлы v24 для новостей и профилей). Не загружай архив ZIP как файл в GitHub — **распакуй содержимое** и перенеси файлы в корень репозитория.

В Render дождись `Live`. Открой Telegram Mini App заново. **Первый приз/спин должен начислиться только после серверного подтверждения.** После одного вращения кнопка заблокирована на 24 часа, и время не сбрасывается при перезапуске.

## Важные детали

- Для сохранения прогресса необходимы корректные `SUPABASE_URL` и `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN` должен быть новым действующим токеном.
- Новая рабочая смена (дополнительная вкладка) сохраняет время старта и конца на сервере. Старый режим коротких подработок основной игры оставлен без изменения.
- Стартовая локация игрока и купленные квартиры не сбрасываются.
- Результаты казино в игре виртуальные. В нём используются SVG-значки вместо emoji.
- При редком выпадении уже имеющейся вещи предусмотрена компенсация виртуальными деньгами.
- Перед заменой сделай резервную копию GitHub и Supabase. Проверяй реальные устройства перед публикацией для друзей.
