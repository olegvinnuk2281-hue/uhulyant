# Ухилянт v23.3 — восстановление входа через Telegram

## Причина ошибки
В версии v23.1 не были включены серверный маршрут `/api/telegram/auth` и Telegram-логика файла `uhylyant-account.js`. Поэтому приложение показывало стандартный вход по логину/паролю вместо автоматического Telegram-входа.

## Что исправлено
- Добавлен официальный Telegram Mini App SDK в HTML.
- Автоматическая авторизация через `Telegram.WebApp.initData` с **проверкой HMAC SHA-256 на сервере**.
- Повторный вход открывает тот же профиль (`telegramId` в Supabase), а не создаёт нового игрока.
- Новый Telegram-пользователь получает сохранённый стартовый аккаунт.
- В Telegram не требуется логин или пароль; при ошибке выводится диагностика.
- Сохранена отдельная форма входа для обычного сайта.
- В «Акаунт» можно привязать старый логин/пароль к Telegram, чтобы перенести доступ на прежний профиль.
- Исправлено накопление данных Supabase свыше первой тысячи игроков.
- Отключена гостевая авторегистрация при запуске через Telegram до проверки подписи.
- После получения игрового состояния скрывается окно создания нового персонажа, если профиль уже создан.
- Оформление казино и существующие игровые механики **не менялись**.

## Установка поверх v23.1
1. Сделай резервную копию GitHub и Supabase.
2. **В корне GitHub замени три файла из архива-патча:** `server.js`, `uhylyant-account.js`, `uhylyant.html`.
3. Не удаляй `assets`, `uhy-polish.css`, `uhy-polish.js`, `uhylyant-ui.js`, `package.json` и остальные существующие файлы.
4. Commit changes / Push. В Render подожди, пока сборка получит статус **Live**.
5. В Render → Environment проверь `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`.
6. В BotFather Mini App должен быть указан именно адрес, с которого загружается игра: `https://uhulyant.onrender.com` (проверь домен на своём Render).
7. Полностью закрой Mini App в Telegram и открой игру **кнопкой Mini App** внутри @Uhilyant_UAbot.
8. При первом входе Telegram авторизует профиль; при следующем открытии откроется тот же аккаунт.

**Важно:** Telegram-токен ранее был опубликован в переписке. Отзови его через @BotFather и создай новый. Настоящий токен храни только в Render Environment. Ни в GitHub, ни в скриншоты токены не добавляй.

## Тесты
- 13 автоматических тестов маршрутов Telegram-авторизации, защиты от подмены ID, просрочки подписи, повторного входа и привязки старого аккаунта — пройдены на локальном тестовом сервере с имитированной Supabase.
- Проверка синтаксиса `server.js`, `uhylyant-account.js` и встроенных HTML-скриптов — пройдена.
- Chromium не может открывать тестовые страницы в данной среде (ERR_BLOCKED_BY_ADMINISTRATOR). Работа в реальном Telegram с Render/Supabase не проверялась; проверка после деплоя обязательна.

Если при открытии в Mini App появляется сообщение об ошибке, пришли его текст и не показывай токен. Если бот открывает простую внешнюю ссылку вместо Mini App, настрой кнопку через @BotFather.
